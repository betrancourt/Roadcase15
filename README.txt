ROADCASE 15 — installation

Cette version est une PWA (Progressive Web App).

Pour la tester sur ordinateur :
- ouvre index.html dans un navigateur.

Pour l’installer réellement sur iPhone :
1. Mets le dossier en ligne sur un hébergement HTTPS (Netlify, GitHub Pages, OVH, etc.).
2. Ouvre l’adresse dans Safari.
3. Appuie sur Partager.
4. Choisis « Sur l’écran d’accueil ».

Fonctions incluses :
- programme quotidien 15 minutes ;
- mode vacances et journée VTT ;
- chrono et tours ;
- historique, score Boss, XP et niveaux ;
- badges ;
- poids, tour de taille, tour de poitrine ;
- photos mensuelles ;
- export/import des données ;
- fonctionnement hors connexion après installation.

Important :
les données sont stockées localement dans le navigateur de l’appareil.
